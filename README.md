## Descripción

Este proyecto consiste en desarrollar un simulador de Pokémon utilizando
Programación Orientada a Objetos (POO) en Python.
El programa permite crear, entrenar, visualizar, enfrentar y liberar Pokemon mediante un menú interactivo. Además, implementa conceptos fundamentales de POO como clases, objetos, atributos, métodos, constructores, destructores, métodos de clase y sobrecarga de métodos mediante parámetros variables.

## Archivos del proyecto

- `main.py` → Contiene el menú principal y la interacción con el usuario.
- `clases/pokemon.py` → Contiene la definición de la clase `Pokemon`.

## Funcionalidades

- Capturar un Pokemon.
- Entrenar un Pokemon.
- Mostrar la información de los Pokemon registrados.
- Simular una batalla entre dos Pokemon.
- Mostrar el total de Pokemon creados.
- Liberar un Pokemon.
- Salir del programa.

## Conceptos aplicados

- Clases y objetos.
- Constructor (`__init__`).
- Destructor (`__del__`).
- Variables de instancia.
- Variables de clase.
- Métodos de instancia.
- Método de clase (`@classmethod`).
- Sobrecarga de métodos utilizando `*args`.
- Uso de `self`.
